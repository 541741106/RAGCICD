## 推进方式

- 每次推进一个可验收的小任务，通过功能分支、Issue 和 PR 留下记录。
- 教学任务先说明概念、输入输出和验收标准，再由学习者练习关键部分并检查结果；明确要求助手实现的内容可直接完成。
- 新增目录随功能需要创建；不提前生成整个项目。
- Conda 管理解释器和环境，`pyproject.toml` 管理项目、Python 依赖及工具配置。
- 本地硬件资源有限，生成模型调用云端 API；Embedding 与 Reranker 的选择结合实际内存、延迟和成本验证。

## 开发与评测原则

- 普通 PR 的 CI 不调用付费 LLM、不下载大型模型。
- 真实模型评测单独手动触发，记录代码与模型版本、数据集版本、配置、质量、延迟和成本。
- 实验结论来自实际结果，不编造指标。
- 使用与所选 Haystack 版本一致的官方教程，并记录版本和来源。
- 开发集用于调参，测试集用于最终评估；不根据测试集结果反复选择配置。
